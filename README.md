# health_management_project
**11주차: 모듈 1 (health_db.py) - 완료**

목표: 건강정보를 클래스로 만들고 4가지 파일 형식으로 저장·읽기

구현 내용

HealthRecord 클래스: 식별번호, 이름, 생년, 성별, 키, 몸무게를 저장하고 BMI와 비만도를 자동 계산, to_dict()로 딕셔너리 변환
HealthManager 클래스: 레코드 목록 관리, add_record()로 추가하며 식별번호(P2026-0001 형식) 자동 생성, print_records()로 화면 출력
파일 저장/읽기 메소드 (모두 try-except로 예외 처리, 실패 시 빈 리스트 반환)
